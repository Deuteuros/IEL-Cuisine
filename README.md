# IEL - Cuisine (Lakozia)

Application Flutter pour l'**affichage des commandes en cuisine**. Interface Kanban permettant aux cuisiniers de visualiser et gérer les commandes entrantes en temps réel.

## Fonctionnalités

- Vue Kanban pour le suivi des commandes
- Mise à jour en temps réel via WebSocket
- Interface optimisée pour les écrans de cuisine (dark mode)

## Stack technique

- **Framework** : Flutter (Dart)
- **Architecture** : Riverpod (Provider)
- **UI** : Material 3, Google Fonts (Outfit)
- **Communication** : WebSocket
